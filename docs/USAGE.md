# Unzip 使用手册

## 首次打开

应用为纯本地工具，不需要联网，也不会申请存储权限——所有文件都通过 Android 系统的「文件选择器」（SAF）访问，你选中哪个文件/文件夹，应用才拿到那个位置的临时访问权。

首页三块区域：

1. 顶部标题栏，右上角齿轮进入**设置**。
2. 两个入口卡片：**打开压缩包**、**创建压缩包**。
3. 下方是**最近打开**记录和支持格式清单。

## 浏览与解压

1. 点「打开压缩包」，在系统选择器里选一个压缩文件。
2. 进入浏览页后顶部显示格式、条目数、原始大小、压缩率；支持搜索框过滤。
3. 点文件夹进入下一级，顶部面包屑可返回任意上级；系统返回键先回上级目录，再回首页。
4. 长按文件进入多选（或单击文件直接选中），底部出现「解压选中」；不选直接点「解压全部」。

### 解压流程

1. 点「解压全部」或「解压选中」后弹出确认框。
2. 点「选择目标文件夹」用系统选择器挑一个目录（会记住，之后可设为默认）。
3. 选择重名处理方式：**覆盖 / 跳过 / 自动重命名**。
4. 点「开始解压」。底部会显示进度卡片，可随时取消；切到后台会以通知形式继续。
5. 完成后从文件管理器进入目标目录查看。

### 加密压缩包

打开时若检测到需要密码，会弹出密码框。密码错误会提示并允许重新输入（错误页也有「重新输入密码」按钮）。支持：

- ZIP 传统加密（ZipCrypto）
- ZIP AES-256
- 7Z AES-256
- RAR 加密（RAR4/RAR5）

## 创建压缩包

1. 点「创建压缩包」。
2. 用「选择文件」（可多选）或「选择文件夹」添加内容；已选条目右侧 × 可移除。
3. 输入压缩包名称（选择格式时会自动补扩展名）。
4. 选择格式：ZIP / 7Z / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ / TAR.ZST / GZ / BZ2 / XZ / ZST。
   - 单文件格式（GZ/BZ2/XZ/ZST）只能选一个文件。
5. 拖动「压缩级别」滑块（0–9，越大越小越慢）。
6. 点「开始压缩」，在系统「保存到」界面选择保存位置。
7. 完成后底部任务卡片可点「打开」直接查看产物。

## 设置

- **主题**：跟随系统 / 浅色 / 深色。
- **默认解压目录**：选一次，以后解压默认用它。
- **重名文件策略**：作为默认值带入解压确认框。
- **支持格式**：查看当前能读/能写的格式。
- **关于**：版本与开源组件说明。
- **清空最近记录**。

## 常见问题

**打开时提示「打开失败」**
- 文件可能损坏，或扩展名与真实格式不符（应用会优先按文件头识别）。
- 若是加密包，确认密码正确。

**解压/压缩到一半失败**
- 目标目录权限失效（比如重启后 SAF 授权丢失）：重新选择目标目录。
- 存储空间不足：清理后重试。
- 部分条目损坏时会跳过并继续，任务结束后在结果里提示。

**任务切到后台还在跑吗**
- 会。任务由前台服务承载，通知栏有进度条；取消只能从应用内或通知（应用内底部卡片）。

**为什么不能解压分卷包**
- 当前版本未实现分卷（ZIP/7Z/RAR 分卷）合并，属已知限制。

**RAR 能压缩吗**
- 不能。RAR 是专有格式，没有开源编码器；只支持读取。
